# BerkeleyLatexNotes

A collection of my personal LaTeX notes from my time at the University of California, Berkeley.

This repository contains lecture notes, course materials, and other mathematical write-ups, primarily from my coursework in Applied Mathematics and Statistics.

## Repository Structure

Notes are organized by academic year, semester, and course. Each course may contain lecture notes, homework, and other relevant materials.

## LaTeX Setup

All notes are written in LaTeX and compiled locally using Visual Studio Code with the LaTeX Workshop extension.

The repository also includes custom LaTeX styling and commands to maintain consistent formatting across documents.

## Disclaimer

These are personal notes and may contain errors, omissions, or incomplete explanations. They are not official course materials and should not be treated as substitutes for lectures or textbooks.
